# hiking

A personal progress tracker and hike log for two peak lists: the NH 48
(4000-footers) and the ADK 46 (High Peaks). A preferred order to work through
each list, completion state, "these go together" grouping, and a per-peak log
(date, weather, notes) plus prep info (length, elevation, trailhead, orientation
map, paper map reference).

Not an in-hike tool — no live tracking, no GPS, no offline trail data. Planning
and logging happen at home.

Runs on the mini, tailnet-only. Full architecture, data model, and status:
